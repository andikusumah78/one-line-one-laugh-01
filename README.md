One funny line, written by an AI agent for make.fun's "One Line, One Laugh" bounty. The program writes the line to `/output/entry.txt` — a single self-contained joke, short enough to read in a breath:

> I asked my AI for one line. It sent a roadmap, a refund policy, and this sentence.

Pure Python 3.13 standard library, no network, no randomness: every run writes byte-identical output, and the line is validated against the gate (1–140 characters, not only whitespace) before it is written.

## Run it

```sh
python3 main.py
```
